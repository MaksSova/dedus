# Проверка конкурсной поставки

Дата: 27 октября 2026 года. Среда фактической проверки: Windows, Python 3.12.14. Минимальная заявленная версия проекта — Python 3.11; отдельный запуск на Python 3.11 и Linux пока не проводился.

## Проверено из отдельной конкурсной папки

- `python -m unittest discover -s max_tutor/tests -q`: 46 тестов, все успешно.
- Внутри проверок валидаторов используются три файла с 256 проверочными случаями; они включены в комплект. Это часть тестов, а не дополнительные 256 отдельных unittest-тестов.
- Каталог загружается без исходных PDF: 10 пакетов, 185 карточек, два предмета.
- `python -m max_tutor demo --output .local/demo.json`: автоматическое занятие завершено, запросов GPT — 0.
- Девять публичных маршрутов мини-приложения возвращают 200 и непустые файлы: главная страница, скрипт, два CSS и пять демо.
- Проверка по списку разрешённых файлов и поиск характерных секретов в текстовых файлах выполнены скриптом `scripts/check_release.py`.

Проверки используют временные базы; реальная история учеников не копировалась. Тестовые токены в тестах — фиктивные строки. Открытый сертификат в certs не является приватным ключом.

Дополнительно ZIP распакован в отдельную временную папку: все 46 тестов прошли повторно. Контрольные суммы исходных файлов совпали с манифестом. Проверка содержимого архива на точное совпадение с действующими секретными ключами выполнена без вывода значений; совпадений нет.

## Ранее проверено на действующем MAX-боте

Проверены токен, получение событий и отправка сообщений. После очистки старых меню API MAX подтвердил удаление 19 клавиатур; дополнительное чтение сообщений подтвердило сохранение текста и актуальной клавиатуры. Эти проверки не заменяют демонстрацию текущего развёртывания перед защитой.

## Что ещё нужно проверить перед выступлением

- Участник добавляет реальные обезличенные скриншоты; автоматическая проверка не анализирует личные данные на изображениях.
- Пройти один полный учебный диалог на действующем боте с интернетом, включая «Пишу…», подсказку и завершение.
- Подтвердить доступность бота на время проверки жюри. Компьютерный процесс не равен круглосуточному размещению на сервере.
- Конкурсный GitHub-репозиторий ещё не опубликован; ссылка будет получена при создании репозитория.

При сборке ZIP формируется SHA256SUMS.txt для исходных файлов и отдельная контрольная сумма архива. Команда сборки не включает .env, .env.max, .local, базы, логи, PDF и кэши, даже если они появились после локального запуска.
