# Авторство и процесс разработки

Автор конкурсного проекта: **Савенков Максим**, возрастная категория 11–14 лет. Название проекта — «Репетитор», демонстрационный бот в MAX — «Дедус».

Личный вклад участника, подтверждённый им при подготовке материалов:

- Придумывал учебные сценарии и выбирал задачи.
- Тестировал логику диалога и ответы GPT, находил ошибки и непонятные объяснения.
- Формулировал замечания и повторно тестировал после исправлений.
- Предлагал изменения интерфейса: скрыть недоступную визуализацию, удалять устаревшие кнопки, показывать «Пишу…» при ожидании GPT.

Python-код создавался и исправлялся при помощи ИИ-помощника в Codex. Это не представляется как самостоятельное ручное написание участником каждой строки кода. Аватар вымышленного преподавателя создан с помощью midjourney.

GPT внутри работающего бота — отдельное использование ИИ: он анализирует учебные сообщения и формулирует объяснения. Его роль не следует смешивать с помощью при разработке программного кода.
