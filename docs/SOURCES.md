# Источники и условия использования

## Учебные материалы

- Л. Э. Генденштейн и соавторы. «Решение ключевых задач по физике для основной школы. 7–9 классы», 2013.
- Ю. Н. Макарычев, Н. Г. Миндюк, К. И. Нешков, С. Б. Суворова. «Алгебра. 8 класс», под редакцией С. А. Теляковского, издание 2024 года.

Карточки содержат ссылки на источники, адаптации примеров, тренировочные упражнения и подготовленные пояснения. Конкретное происхождение указано в полях source/sources каждой карточки. Упражнения с kind=original обозначены как авторские тренировочные материалы проекта; они не выдаются за задания из учебника. Полные PDF и сканы книг не включены. Пути к локальным PDF удалены из конкурсной копии.

Указание источника само по себе не является лицензией на произведение. Права на учебники принадлежат соответствующим правообладателям. Проект не объявляет их материалы общественным достоянием и не распространяет на них лицензию собственного кода. Публичная лицензия на весь комплект сейчас не назначена; это не означает автоматического разрешения на любое повторное использование.

## Графика

Аватар вымышленного учителя создан с помощью встроенного Imagegen. Сохранён окончательный запрос `docs/assets/avatar-prompt.txt`. Фотографии реальных людей не использовались как исходное изображение аватара. Скриншоты бота добавляет участник; они должны быть обезличены.

- MAX: https://dev.max.ru/docs-api
- Редактирование клавиатур: https://dev.max.ru/docs-api/methods/PUT/messages
- Webhook: https://dev.max.ru/docs-api/methods/POST/subscriptions
- Мини-приложения: https://dev.max.ru/docs/webapps/introduction
- OpenAI Responses API: https://developers.openai.com/api/reference/resources/responses/methods/create
- Структурированные ответы: https://developers.openai.com/api/docs/guides/structured-outputs

`certs/russian-trusted-root.pem` — публичный корневой сертификат, не приватный ключ. Скачан с официального адреса Госуслуг по проверенному HTTPS. Адрес, дата и SHA256 сертификата приведены в `certs/SOURCE.txt`. Файл подключается только клиентом MAX.
